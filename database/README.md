# Database

This folder contains a small exemplar database of instances conforming to chemrof.

It was created (2021–2024) by ETL from two main sources:

 - CHEBI
 - Wikidata

The SPARQL CONSTRUCT pipeline that produced it has been retired (it is
in git history as `etl.mk` and `sparql/`), so these files are a frozen
snapshot.

For more info see: [database section of docs](https://w3id.org/chemrof/database/)
